# NEBULA

NEBULA is a decentralized federated learning platform designed to train machine learning models across distributed devices while preserving data privacy and enabling real-time experimentation and monitoring.

## Highlights

- Decentralized federated learning
- Privacy-preserving training on distributed devices
- Modular architecture for experimentation and orchestration
- Real-time monitoring and management of learning processes
